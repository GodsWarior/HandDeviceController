# HandDeviceController

Управление курсором мыши жестами руки через веб-камеру.
Проект использует компьютерное зрение (MediaPipe + OpenCV) для распознавания
жестов пальцев и библиотеку PyAutoGUI для управления курсором и кликами.

## Возможности

- 🖐️ **Перемещение курсора** — сомкните указательный и большой пальцы.
- 🖱️ **Клик (ЛКМ)** — сомкните большой, указательный и средний пальцы.
- 📜 **Скроллинг** — жест из двух режимов (пальцами и «кулак» с большим+безымянным).
- ⚙️ **Настройка чувствительности** прямо во время работы (`+` / `-`).
- 🚀 **Фоновый режим** — окно скрывается, обработка жестов продолжается.
- 🧩 **Конфигурация** через `config.json`.

## Требования

- Python 3.11+
- Веб-камера
- ОС: Windows / Linux / macOS (оптимизация приоритета процесса — только Windows)

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/GodsWarior/HandDeviceController.git
cd HandDeviceController

# 2. (Рекомендуется) создать виртуальное окружение
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление (горячие клавиши)

| Клавиша | Действие |
|---|---|
| `Q` / `Esc` | Выход |
| `+` / `-` | Увеличить / уменьшить чувствительность |
| `R` | Сбросить настройки к значениям по умолчанию |
| `M` | Вкл/выкл оптимизацию при свёрнутом окне |
| `B` | Вкл/выкл фоновый режим (окно скрыто, но не свёрнуто) |

## Настройка

Основные параметры задаются в `config.json`:

```json
{
  "camera": { "device_index": 0, "frame_width": 640, "frame_height": 480, "fps": 30 },
  "sensitivity": { "x": 1.8, "y": 1.5 },
  "thresholds": { "move": 0.05, "click": 0.06 },
  "dead_zone_ratio": 0.1,
  "click_cooldown_seconds": 0.5,
  "smoothing": 3
}
```

Если файл отсутствует или повреждён, используются значения по умолчанию.
